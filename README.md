# Search Funnels (Google + AI)

Service page for ImageWorks Creative, published with GitHub Pages:
https://imageworksc.github.io/search-funnels/

## Structure

```
index.html        Page markup (no inline styles or scripts)
css/styles.css    All styles: tokens, components, sections, responsive rules
js/main.js        Scroll reveal, navigation drawer, steps accordion
assets/img/       Logos
```

## Responsive

Tested from 320px phones through tablets, desktop, QHD, 4K (3840px) and 5K (5120px).
Above 2200px the layout scales up with `zoom` so it keeps its proportions on large displays.
